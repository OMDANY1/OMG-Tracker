# OMG — إصلاح سبب حلقة المراجعات

الحالة: الملفات الخمسة المصححة نُفذت داخل PostgreSQL محلي مدمج، ونجح 39 سيناريو تشغيل SQL. هذه نتيجة اختبار قاعدة البيانات محليًا، وليست إعلان نشر التطبيق أو اعتماد Supabase السحابي.

## السبب المثبت

كان التسليم السابق يعتمد على اختبارات نصوص/Fixtures وبناء TypeScript دون تنفيذ SQL. لذلك مرّت أخطاء مثل مفتاح أجنبي غير صالح، ونص SQL تالف، ومنح صلاحيات لتوقيعات دوال غير موجودة، واستخدام قيم Enum غير معرفة.

تقرير V3.5 نفسه يقول صراحة إن الاتصال السحابي غير موجود وإن الاختبارات الحية Blocked. لا يوجد دليل أنه اعتقد أن القاعدة مربوطة. المشكلة كانت في عدم الفصل عمليًا بين منع تغيير قاعدة التشغيل وبين السماح باختبار قاعدة محلية مؤقتة. كذلك اتساع برومبتات التصحيح دون بوابة تشغيل SQL سمح بعودة أخطاء جديدة.

الحزمة تغير طريقة التسليم: ملفات مصححة + محرك SQL قابل للتشغيل + اختبارات سلوك + ناتج التشغيل. لا تحتاج هذه الاختبارات Docker أو مفاتيح Supabase أو ملف إعداد اتصال بالتطبيق.

## الموجود في الحزمة

- `migrations/`: الملفات الخمسة المصححة، وهي وحدها التي تُنسخ إلى `supabase/migrations/` في المشروع الحالي الخالي من الهجرات المطبقة.
- `verification/`: محرك الاختبار Node.js مع `package.json` و`package-lock.json` واختبارات SQL الفعلية.
- `RPC_CONTRACT.json`: أسماء ومعاملات وصلاحيات الدوال العامة، مستخرجة من كتالوج PostgreSQL بعد تنفيذ الملفات.
- `evidence/`: سجل فشل النسخة الأصلية، سجل نجاح الإصلاح، والفرق الفعلي بين الملفات.
- `REPORT.md`: نطاق الإصلاح وحدود الأدلة.
- `ANTIGRAVITY_NEXT_STEP.md`: مهمة قصيرة ومحددة لمطابقة كود التطبيق الموجود عندك.
- `SHA256SUMS.txt`: بصمات الملفات النهائية.

## تشغيل الاختبار محليًا

يتطلب Node.js 20 أو أحدث، وإنترنت لتنزيل حزمة NPM في المرة الأولى فقط. من داخل مجلد `verification`:

```sh
npm ci --ignore-scripts
npm test
```

النتيجة المتوقعة: `RESULT 39 PASSED, 0 FAILED`.

كل تشغيل ينشئ قاعدة PostgreSQL في الذاكرة ويغلقها عند الانتهاء. لا يقرأ الاختبار بيانات اتصال مشروعك، ولا يتصل بداتا بيز سحابية. بيانات المصممين الاختبارية وحسابات `example.test` وجلسات الاختبار توجد في الاختبار فقط؛ ملفات البذر لا تحتوي جلسات عمل وهمية.

إذا ظهر خطأ تشغيل، احتفظ برسالة الخطأ كاملة. لا تغيّر الاختبار ليعلن النجاح، ولا تستخدم تقارير النسخ القديمة بديلًا عنه.

## الخطوة التالية

أرسل الحزمة إلى Antigravity مع محتوى `ANTIGRAVITY_NEXT_STEP.md`. المطلوب حاليًا مطابقة خدمات التطبيق والأنواع واستدعاءات RPC بالملفات المصححة واختبارها. الربط السحابي والنشر مرحلتان لاحقتان منفصلتان.

قاعدة التشغيل السحابية لم يتم الاتصال بها أو تغييرها في هذا الإصلاح. كود التطبيق على جهاز Windows لم يكن ضمن الملفات المرفوعة هنا، ولذلك لم يُعدّل ولم يُبنَ في هذه الجلسة.
