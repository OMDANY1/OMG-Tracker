# مساحة عمل أو إم جي الإبداعية — OMG Creative Workspace

تطبيق ويب تشغيلي متكامل ومصمم خصيصاً لوكالات الدعاية والإعلان (Advertising Agencies) لإدارة المصممين، وتتبع الحسابات الـ 28، وتوليد مهام الكامبينز، وتسجيل جلسات العمل الحقيقية بالسيرفر، وتدفق اعتمادات المراجعة الداخلية، وإصدار التقارير الشهرية المعتمدة وحزم التحليل بصيغة ZIP.

---

## 1. المعمارية الفنية والتقنيات المستخدمة

- **واجهة المستخدم والأطر البرمجية**: Next.js 14+ (App Router) مع TypeScript وتصميم عربي أصيل يدعم RTL بالكامل (`dir="rtl"`).
- **التصميم وتنسيق الصفحات**: Tailwind CSS، وخط Cairo العربي، مع لوحة ألوان هادئة ومريحة مخصصة لأدوات العمل الداخلية (Navy/Slate/Teal).
- **قاعدة البيانات والتخزين**: Supabase PostgreSQL مع تفعيل أمان الصفوف (RLS)، ومحددات منع التضارب (Exclusion Constraints & Partial Unique Index) لمنع تشغيل أكثر من عداد واحد للشخص.
- **المنطقة الزمنية الرسمية**: `Africa/Cairo` (توقيت القاهرة) لضبط بدايات ونهايات الأشهر وتجزئة الجلسات المتداخلة.

---

## 2. أقسام النظام التسعة (Navigation Sections)

1. **نظرة عامة (`/`)**: لوحة تحكم المدير العام ومؤشرات الأداء المباشرة (المهام المفتوحة، قيد التنفيذ، المراجعة الداخلية، العملاء المتوقفون بعائق، وتوزيع الـ 28 عميلاً حسب الصعوبة).
2. **شغلي (`/my-work`)**: البوابة اليومية للمصمم (المهام ذات الأولوية، المهام المطلوب عليها تعديلات مع ملاحظات المراجع، والتحكم السريع في عداد الوقت).
3. **التاسكات (`/tasks`)**: لوحة كانبان وجدول بيانات تفصيلي مع فلاتر ذكية وتوليد سريع ونظام مراجعة يمنع الموافقة الذاتية.
4. **العملاء (`/clients`)**: إدارة الـ 28 حساباً المحددة بدقة، مع أداة النقل الآمن للمسؤوليات دون مساس بسجلات العمل السابقة.
5. **الكامبينز (`/campaigns`)**: نطاق الحملات، ومولد باقات المهام السريعة (مثل: "Post 01 ... Post 12") مع مسودة قابلة للمعاينة والتعديل قبل الحفظ.
6. **سجل الشغل (`/time-ledger`)**: دفتر الساعات الكامل، وتصنيفات العمل الخمسة، وإبطال الجلسات بذكر السبب دون حذف إتلافي، وتصدير CSV مع حماية حقن المعادلات.
7. **التيم (`/team`)**: أعضاء الفريق الستة والمدير العام، وأسبوع العمل، وحساب معدل الحمل المخطط (Planned Load Ratio).
8. **التقارير الشهرية (`/reports`)**: اختيار الشهر (مثل سبتمبر 2026)، وتجميد اللقطات التاريخية (Immutable Snapshots)، وتحميل حزمة التحليل (Analysis Pack ZIP)، وتصميم جاهز للطباعة وتصدير PDF.
9. **الإعدادات (`/settings`)**: ضبط المنطقة الزمنية، وفحص الاتصال الحي بـ Supabase، ودليل تهيئة الحسابات الحقيقية.

## 4. خطوات التشغيل المحلي (Local Setup)

### المتطلبات الأساسية:
- Node.js إصدار 18 أو أحدث (تم الاختبار على Node v24 بنجاح).
- مدير الحزم npm.

### أوامر التشغيل:
```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل حزمة اختبارات القبول الشاملة (30 اختباراً مؤتمتاً)
npm run test

# 3. بناء نسخة الإنتاج
npm run build

# 4. تشغيل خادم التطوير المحلي
npm run dev
```

التطبيق سيعمل مباشرة على: `http://localhost:3000`

## 5. خطوات الربط بقاعدة بيانات Supabase الحقيقية

1. أنشئ مشروعاً مخصصاً جديداً على منصة [Supabase](https://supabase.com).
2. افتح نافذة **SQL Editor** في لوحة تحكم Supabase وقم بتشغيل ملفات الـ SQL بالترتيب من مجلد `supabase/migrations`:
   - `20260906000001_initial_schema.sql` (الجداول والأنواع)
   - `20260906000002_constraints_and_functions.sql` (محددات التضارب والدوال التبادلية)
   - `20260906000003_rls_policies.sql` (قواعد أمان RLS والتخزين السحابي)
   - `20260906000004_seed_roster_and_clients.sql` (بذر الحسابات الـ 28 وأعضاء الفريق)
   - `20260906000005_monthly_report_functions.sql` (دوال الحسابات الشهرية التراكمية)
3. أنشئ ملف `.env.local` في مسار المشروع وضع فيه المفاتيح المخصصة:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://[YOUR-PROJECT-REF].supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-publishable-key
   SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
   DATABASE_URL=postgresql://postgres:[YOUR-PASSWORD]@db.[YOUR-PROJECT-REF].supabase.co:5432/postgres
   ```
4. افتح شاشة "الإعدادات" في التطبيق واضغط على **"إعادة الفحص"** للتحقق الفعلي من نجاح الاتصال وتأكيد عدد الحسابات المقروءة حياً من قاعدة البيانات.

## 6. دليل الاستخدام التشغيلي (Click-by-Click Guide)

1. **التبديل بين الهويات**:
   من الشريط العلوي، يمكنك التبديل بين "عماد (Owner & Art Director)"، "ندى (Senior Reviewer)"، "سارة (Designer)"، "آية (Junior)" لتجربة الصلاحيات وتدفق المراجعة.
2. **إنشاء كامبين وتوليد المهام**:
   - انتقل إلى صفحة **الكامبينز**، واختر العميل "wael samir" واضغط "توليد باقة مهام (Post 01 ... 12)".
   - عاين المسودة، ثم اضغط تأكيد ليتم إدراجها فورياً للمصممة سارة.
3. **تسجيل جلسة العمل بالعداد أو يدوياً**:
   - انتقل إلى صفحة **شغلي** (كسارة)، واختر المهمة "Post 01" واضغط **"تشغيل العداد"** لبدء جلسة حية، أو اضغط **"إضافة جلسة عمل يدوية"** وأدخل التاريخ 2026-09-06 من 11:00 إلى 12:00 بتوقيت القاهرة لتسجيل 60 دقيقة كاملة.
4. **دورة المراجعة الداخلية**:
   - اضغط **"طلب مراجعة"** وضع رابط المعاينة ليتم نقل المهمة تلقائياً إلى حالة "مراجعة داخلية" وتعيين عماد كمراجع افتراضي.
   - إذا حاول المصمم اعتماد مهمته بنفسه فسيتم رفض العملية برمجياً لمنع الموافقة الذاتية.
5. **استخراج التقرير الشهري وحزمة التحليل**:
   - ادخل إلى قسم **التقارير الشهرية** واختر "سبتمبر 2026".
   - اضغط **"تحميل حزمة التحليل (ZIP)"** للحصول على 4 ملفات CSV معقمة من حقن المعادلات + تقرير Markdown متوافق للتحليل مع ChatGPT.
   - اضغط **"تجميد واعتماد التقرير"** لإنشاء لقطة تاريخية مجمدة لا تتأثر بأي تعديلات لاحقة.
